# МФЦ — Python Flask MVP

## Что есть
- Flask
- SQLite через SQLAlchemy
- База данных создаётся автоматически при первом запуске
- Таблицы `services` и `messages`
- Каталог услуг загружается из БД
- Сообщения из демонстрационного чата сохраняются в БД
- Три темы: синяя, белая, тёмная
- Настройки темы
- Базовая навигация и кнопки
- Минималистичный интерфейс без эмодзи

## Запуск

Создать виртуальное окружение (рекомендуется):

Windows:
    python -m venv .venv
    .venv\Scripts\activate

Установить зависимости:
    pip install -r requirements.txt

Запустить:
    python app.py

Открыть:
    http://127.0.0.1:5000

БД:
    data/mfc.db

Если файл БД ещё не существует, Flask создаст его автоматически.
