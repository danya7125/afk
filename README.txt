# MFC AI — Python MVP UI

Первый макет проекта уже перенесён на Python-стек.

Стек:
- Python
- Flask
- HTML
- CSS

Сейчас это только интерфейс. Нейросеть, база данных и настоящий голос пока не подключены.

## Запуск

1. Установить Python.
2. Установить Flask:
   pip install flask
3. Открыть папку проекта в VS Code.
4. Выполнить:
   python app.py
5. Открыть адрес, который покажет Flask, обычно:
   http://127.0.0.1:5000

## Структура

app.py
templates/index.html
static/style.css

Следующим этапом можно добавить обработчик /chat и подключить ИИ.
